# SIM800L ↔ Telegram Bridge

Мост между GSM-модулем **SIM800L** и **Telegram** на базе **ESP8266**.
Входящие SMS и звонки пересылаются в Telegram-чат, а из Telegram можно отправлять SMS (в том числе на кириллице).

## Возможности

- 📩 **Входящие SMS → Telegram** — номер отправителя и текст (PDU-режим, корректно декодируется кириллица).
- 📤 **Отправка SMS из Telegram** — командой `/sms +79001234567 текст`, кодировка UCS2 (кириллица работает).
- 📞 **Уведомления о входящих звонках** — номер звонящего (через `AT+CLIP`), при необходимости — автоматический сброс вызова.
- 📊 **Статус устройства** — Wi-Fi сеть, IP-адрес, уровень GSM-сигнала (CSQ, %, текстовая оценка), состояние звонка.
- 🔄 **Удалённая перезагрузка** командой `/restart`.
- 📶 **Настройка Wi-Fi через веб-портал** (WiFiManager) — пароль от сети в прошивку вшивать не нужно.
- 🔐 Бот отвечает только на сообщения из заданного `CHAT_ID`.
- ⚠️ Контроль SIM-карты при старте: сообщение, если SIM требует PIN, и автоперезагрузка, если SIM не готова за ~40 секунд.

## Команды бота

| Команда | Описание |
|---|---|
| `/sms +номер текст` | Отправить SMS. Пример: `/sms +79001234567 Привет, как дела?` |
| `/status` | Wi-Fi, IP, уровень сигнала GSM, автоотбой, активный звонок |
| `/restart` | Перезагрузить ESP8266 |
| `/help`, `/start` | Список команд |

## Что понадобится

- Плата на **ESP8266** с пинами `D1`/`D2`: NodeMCU v2/v3, Wemos D1 mini и т.п.
- Модуль **SIM800L** + антенна.
- SIM-карта **без PIN-кода** (отключите PIN, вставив SIM в телефон), с поддержкой 2G.
- Питание для SIM800L **3.7–4.2 В, до 2 А в пике**: аккумулятор 18650 или DC-DC понижающий преобразователь (LM2596, MP1584 и т.п.), выставленный на ~4.0 В.
- Электролитический конденсатор **470–1000 мкФ** по питанию SIM800L (крайне желательно).
- Опционально: резисторы 10 кОм + 20 кОм для делителя на линии TX ESP → RX SIM800L.

## Схема подключения

```
                      ┌──────────────────────┐
  Li-ion 3.7–4.2 В    │       SIM800L        │
  или DC-DC 4.0 В     │                      │
  (+) ────────┬───────┤ VCC                  │
              │       │                      │
            ═══ 1000µF│                      │
              │       │                      │
  (−) ────────┴───┬───┤ GND                  │
                  │   │                      │
                  │   │ TXD ─────────────────┼──────► D2 (GPIO4)  ┐
                  │   │                      │                    │
                  │   │ RXD ◄────[делитель]──┼─────── D1 (GPIO5)  │  ESP8266
                  │   │                      │                    │  (NodeMCU /
                  │   │ RST — не подключать  │                    │   D1 mini)
                  │   └──────────────────────┘                    │
                  └──────────────────────────────────────── GND   ┘
                                                  питание ESP — от USB
```

| SIM800L | ESP8266 | Примечание |
|---|---|---|
| VCC | — | Отдельный источник 3.7–4.2 В / 2 А. **Не** от пина 3V3 и **не** от 5V напрямую |
| GND | GND | Земля общая для ESP, SIM800L и источника питания |
| TXD | **D2** (GPIO4) | `GSM_RX` в скетче |
| RXD | **D1** (GPIO5) | `GSM_TX` в скетче; желателен делитель 10к/20к (логика SIM800L — 2.8 В) |
| RST | — | Не подключать (внутри подтянут к VCC) |
| NET | — | Светодиод сети на модуле: мигает раз в 3 с — зарегистрирован в сети |

Делитель на линии D1 → RXD:

```
D1 ──[10 кОм]──┬── RXD SIM800L
               │
            [20 кОм]
               │
              GND
```

> 💡 Самая частая проблема — питание. Если модуль циклически перезагружается, светодиод NET мигает часто (раз в секунду) и не переходит на редкое мигание, или ESP теряет связь с модулем при отправке SMS — проверьте источник тока, толщину проводов и конденсатор.

## Настройка

### 1. Создайте бота и узнайте свой Chat ID

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен вида `1234567890:AAAA...`.
2. Узнайте свой Chat ID, например через [@userinfobot](https://t.me/userinfobot) или [@getmyid_bot](https://t.me/getmyid_bot).
3. Напишите своему боту `/start`, чтобы он мог отправлять вам сообщения.

### 2. Отредактируйте параметры в начале скетча

```cpp
#define BOT_TOKEN "1234567890:AAAA..."   // токен от @BotFather
#define CHAT_ID   123456789              // ваш Chat ID (бот слушает только его)

#define WIFI_SSID "SIM800_Bridge"        // имя точки доступа портала настройки Wi-Fi
#define WIFI_PASS "12345678"             // пароль к этой точке доступа (≥ 8 символов!)

#define AUTO_HANGUP true                 // true — сбрасывать входящие звонки автоматически
#define SMS_SEND_TIMEOUT 8000            // сколько ждать ответа модуля после отправки SMS, мс
```

> ⚠️ `WIFI_SSID` / `WIFI_PASS` — это **не** ваша домашняя сеть, а имя и пароль точки доступа, которую ESP поднимет для первичной настройки (см. ниже). Пароль должен быть не короче 8 символов, иначе WiFiManager создаст открытую точку доступа.

При необходимости можно поменять пины (`GSM_RX`, `GSM_TX`).

### 3. Первое подключение к Wi-Fi

1. После прошивки ESP не найдёт сохранённой сети и поднимет точку доступа с именем `WIFI_SSID`.
2. Подключитесь к ней с телефона/ноутбука паролем `WIFI_PASS` — откроется портал (если нет — зайдите на `http://192.168.4.1`).
3. Нажмите **Configure WiFi**, выберите свою сеть, введите пароль, сохраните.
4. ESP подключится к сети и пришлёт в Telegram: `✅ ESP8266 + SIM800L запущен`.

Данные сети сохраняются во flash. Если сохранённая сеть недоступна дольше ~25 секунд, портал поднимется снова. Если портал закрыть без настройки — ESP перезагрузится.

## Как залить скетч

### Arduino IDE

1. **Поддержка ESP8266.** `Файл → Настройки → Дополнительные ссылки для менеджера плат`:
   ```
   https://arduino.esp8266.com/stable/package_esp8266com_index.json
   ```
   Затем `Инструменты → Плата → Менеджер плат` → установить **esp8266 by ESP8266 Community**.
2. **Библиотеки** (`Скетч → Подключить библиотеку → Управлять библиотеками`):
   - **FastBot** (AlexGyver / GyverLibs) — Telegram-бот
   - **PDUlib** (David Henry) — кодирование/декодирование SMS в PDU
   - **WiFiManager** (tzapu) — портал настройки Wi-Fi

   `SoftwareSerial` входит в состав ядра ESP8266.
3. Склонируйте репозиторий (папка `sim800_telegram_bridge` должна совпадать с именем `.ino`) и откройте `sim800_telegram_bridge.ino`.
4. Выберите плату: **NodeMCU 1.0 (ESP-12E Module)** или **LOLIN(WEMOS) D1 R2 & mini**, порт — COM-порт платы.
5. Нажмите **Загрузить**.

### arduino-cli

```bash
arduino-cli config add board_manager.additional_urls https://arduino.esp8266.com/stable/package_esp8266com_index.json
arduino-cli core update-index
arduino-cli core install esp8266:esp8266
arduino-cli lib install FastBot PDUlib WiFiManager

git clone https://github.com/ArtemDNK/sim800_telegram_bridge.git
cd sim800_telegram_bridge

arduino-cli compile --fqbn esp8266:esp8266:nodemcuv2 .
arduino-cli upload  --fqbn esp8266:esp8266:nodemcuv2 -p /dev/ttyUSB0 .
```

Для Wemos D1 mini используйте FQBN `esp8266:esp8266:d1_mini`, на Windows порт будет вида `COM3`.

## Как это работает

- ESP8266 общается с SIM800L через `SoftwareSerial` на 9600 бод.
- При старте модуль инициализируется: `ATE0` (без эха), ожидание `AT+CPIN?` → `READY`, затем:
  - `AT+CMGF=0` — PDU-режим SMS;
  - `AT+CNMI=1,2,0,0,0` — входящие SMS выдаются сразу в порт и **не сохраняются на SIM** (память SIM не переполняется);
  - `AT+CLIP=1` — определение номера звонящего;
  - `AT+CSMP=17,167,0,0` — параметры отправки SMS.
- Входящая SMS приходит как `+CMT:` + строка PDU, декодируется PDUlib и отправляется в Telegram.
- На `RING` / `+CLIP:` бот присылает номер звонящего; при `AUTO_HANGUP = true` вызов сбрасывается командой `ATH`. При `AUTO_HANGUP = false` после окончания вызова придёт `📴 Вызов завершён`.
- Исходящая SMS кодируется в PDU (UCS2) и отправляется через `AT+CMGS`.

## Ограничения

- Длина исходящей SMS — одна часть: до **70 символов** кириллицей (UCS2) / до 160 латиницей. Длинные (составные) SMS не поддерживаются.
- Входящие составные SMS приходят в Telegram отдельными частями.
- Во время отправки SMS (`SMS_SEND_TIMEOUT`, по умолчанию 8 с) ESP не опрашивает Telegram — команды, присланные в этот момент, обработаются после.
- Отчёт о доставке SMS не запрашивается: `✅ SMS отправлен` означает, что команда передана модулю.
- SIM800L работает только в сетях **2G (GSM 900/1800)** — убедитесь, что оператор в вашем регионе их ещё поддерживает.

## Диагностика

| Симптом | Что проверить |
|---|---|
| В Telegram ничего не приходит после старта | Токен, `CHAT_ID`, вы нажали `/start` у бота, ESP подключён к Wi-Fi |
| `🔐 SIM-карта требует PIN-код!` | Отключите PIN, вставив SIM в телефон |
| `⚠️ SIM не готова после 40 сек` | SIM вставлена правильно, контакты, питание модуля |
| `/status` показывает GSM `-1 (Нет данных)` | Проводка TX/RX (не перепутаны ли), общая земля, питание |
| `/status` показывает CSQ `99` | Значение 99 означает «сигнал не определён» (текстовая оценка при этом некорректна). Нет сети: антенна, покрытие 2G |
| Модуль перезагружается при отправке SMS/звонке | Питание: ток ≥ 2 А, конденсатор, короткие толстые провода |
